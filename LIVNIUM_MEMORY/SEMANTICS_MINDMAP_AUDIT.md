# Semantics Packages and Mind-Map Audit

Date: 2026-07-26

## Executive verdict

This hidden branch contains two related but distinct projects:

1. a refactored semantics workspace built around online 64-dimensional
   skip-gram learning, per-word metabolic state, and SNLI heads; and
2. a conversation/project mind-map that turns paragraphs into a
   cosine-similarity graph and exports a browser-ready JSON artifact.

Both contain useful engineering ideas. Neither validates the strongest
historical language used around them.

- The semantics workspace is an ambitious prototype, not verified “physics of
  meaning.” Its two saved embedding banks and its 16,381 active manifold
  centroids are almost one-dimensional.
- No saved manifold satisfies the code's own graduation condition.
- The surviving SNLI cache has real signal, but a hypothesis-only control
  reaches almost the same held-out score as the full representation.
- The saved classifier is orphaned and incompatible with both surviving
  classifier implementations.
- The surviving “physics accuracy” script compares a fixed model direction
  against an unrelated random target and therefore cannot measure accuracy.
- The mind-map is a legitimate document/conversation explorer, but its actual
  core is MiniLM embeddings, cosine thresholds, greedy anchor neighborhoods,
  and template narration—not a new physical or quantum law.
- The mind-map's selected-edge “tension” increases with semantic similarity,
  while its narrator describes higher tension as conflict. That interpretation
  is internally inverted.

Preserve this branch. Do not cite its old semantic-physics, oracle, Jacobian,
case-study, test-suite, or accuracy language as current evidence.

## Project A — clean-architecture semantics workspace

### Actual architecture

The refactor splits code into three packages:

- `livnium_core`: domain entities, configuration, divergence, manifold engine,
  monitoring, and the 18-feature Euclidean head;
- `livnium_organism`: emergent/scaffold embeddings, per-word repositories,
  metabolic evolution, and diagnostics;
- `livnium_reasoner`: SNLI loader, relation features, classifiers, training,
  and evaluation.

This separation is useful. The package boundaries and repository interfaces are
worth preserving even though the scientific claims do not survive.

### Actual semantic mechanism

The default `EmergentEmbeddingService` is a real tabula-rasa implementation:

- regex word tokenization;
- online skip-gram with negative sampling;
- 64-dimensional input/output embeddings;
- frequency-weighted loss;
- a slowly decaying global learning-rate brake;
- dynamic vocabulary resizing;
- mean aggregation of contextual token vectors.

The optional scaffold service loads `all-MiniLM-L6-v2`. The factory defaults to
the emergent service, so the current factory honors the stated default boundary.

The saved emergent vocabulary is clearly SNLI-derived:

- `next_id`: 16,589
- embedding capacity: 32,062 rows
- embedding dimension: 64

The current and backup banks use the same vocabulary size but contain almost
orthogonal row directions to one another, so they are separate training states,
not a small continuation of one checkpoint.

### Per-word “metabolism”

For each word, the active implementation records:

- centroid;
- mass;
- radius;
- noise;
- velocity;
- age;
- frequency/context count;
- crystallization and stability flags.

The update rule mixes raw context vectors toward the current centroid, trains a
64→32→64 autoencoder, increases mass for consistent contexts, shrinks radius,
and persists the result into a 256-shard repository.

This is a usable stateful vocabulary experiment. Terms such as mass, gravity,
metabolism, crystallization, and extinction are policy metaphors around
ordinary vector averaging, scalar schedules, and autoencoder updates.

## Project B — Livnium domain mind-map

### Actual pipeline

The mind-map performs:

1. paragraph/function-block ingestion from text, Markdown, code, and JSON;
2. sentence embedding with `all-MiniLM-L6-v2` by default;
3. fallback random token embeddings if explicitly selected or if the package is
   missing;
4. pairwise cosine similarity;
5. edge retention above a fixed alignment threshold;
6. connectivity-weighted node mass;
7. greedy, non-overlapping anchor neighborhoods above a higher threshold;
8. deterministic template narration, with optional local-LLM polishing;
9. JSON export for the existing browser viewer.

This is a useful semantic graph and external-memory tool.

It is not quantum, and the basin detector is a greedy graph heuristic despite
the documentation's insistence that it is “not clustering.”

### Tension inversion

The kernel defines:

`divergence = 0.38 - alignment`

and:

`tension = abs(divergence)`

The mind-map stores only edges with alignment greater than 0.4. Therefore every
retained edge obeys:

`tension = alignment - 0.38`

Fresh artifact checks confirm:

- `alignment + divergence = 0.38` for every edge;
- `tension = abs(divergence)` for every edge;
- maximum numerical error for those relations: 0.

Within this selected graph, higher similarity always means higher “tension.”
The narrator nevertheless interprets higher tension as disagreement or
conflict, while calling lower tension aligned understanding.

The basin stability formula is:

`stability = alignment * (1 - tension)`

For retained edges this becomes:

`stability = alignment * (1.38 - alignment)`

It peaks near alignment 0.69 and can penalize stronger similarity beyond that
point. This is why the most aligned saved basins do not receive the highest
stability.

Preserve the raw cosine graph. Do not interpret this selected-edge tension or
stability as semantic conflict until the metric is redesigned and validated.

### Fallback encoder boundary

`SimpleTextEncoder` is an untrained randomly initialized word-embedding mean:

- duplicate text within one encoder maps identically;
- word overlap raises cosine;
- fresh encoder instances produce unrelated coordinates;
- no seed or checkpoint is persisted.

In one focused smoke check:

- duplicate-text cosine in one encoder: 1.0
- same-text cosine across two fresh encoders: about 0.20
- two phrases sharing only “bank”: about 0.59

Exact numbers vary because initialization is unseeded. The fallback is useful
for plumbing tests, not semantic output or reproducible saved graphs.
