## Short conclusion

This archive is one historical experimental lineage copied three times, not
three separate projects.

The best honest saved classifier in this family is `nli_simple`:

- **40.71%** on all 9,824 valid SNLI test examples;
- deterministic for the tested hash seeds;
- materially helped by its saved lexical memory; but
- unable to predict the neutral class in the fresh replay.

The more elaborate v3–v7 generations score only **33.85–36.06%** in ordinary
static inference. Their saved lexical brains are effectively disconnected from
the decisions, and several reported high numbers measure something else:

- v5/v6/v8 debug paths can return the supplied gold label;
- v4's saved rule accuracy is training-set resubstitution;
- v5's 82.32% geometry number predicts labels created by its own geometry
  teacher, whose agreement with SNLI is only 34.17%; and
- the v4 guide's 85.23% is example prose, not a surviving result.

The archive still contains useful components and lessons:

- supervised word-polarity memory;
- basin/collapse/prototype experiments;
- a layered state-machine representation;
- dynamic-time-warping-style semantic alignment;
- an opposition-axis formulation; and
- a clear record of why per-example “geometry shaping,” debug labels, and
  self-generated targets do not establish language understanding.

Preservation role:
**canonical historical pure-vector/geometric NLI lineage and negative-method
evidence**.

## Deterministic encoder boundary

The shared simple-chain encoder seeds each character vector with Python's
process-randomized `hash(letter)`. No saved hash seed accompanies the archive.
Changing `PYTHONHASHSEED` changes v3/v5/v6 results, so those generations are not
exactly reproducible from the artifacts alone.

More fundamentally, a word vector is a normalized sum of its character vectors.
Character order is discarded:

- `cat` equals `act`;
- `not` equals `ton`;
- `dog` equals `god`; and
- `sleep` equals `peels` within floating-point noise.

Positional encoding records the word's position in the sentence, not character
order within the word. A learned dictionary keyed by the complete token can
separate seen anagrams, but unseen words retain the bag-of-letters collision.

Decision: preserve this as a lightweight lexical baseline and explicit negative
lesson. Do not describe it as sequence-aware word geometry.

## Generation-by-generation interpretation

### Legacy `nli`

Intent: letter-by-letter Omcube encoding, quantum collapse, and zero neural
networks, with an expected 55–60% after 20,000 examples.

Artifact reality:

- current source cannot import its missing quantum cell dependency;
- its saved letter store is empty;
- its 5,324-word polarity memory is the same as v4's; and
- no runnable model state supports the expected result.

Decision: **historical origin only**. The 55–60% expectation is unsupported.

### `nli_simple`

Intent: pure vector/cosine classification with a small supervised polarity
lexicon.

Artifact reality:

- best honest generation in this archive at 40.71%;
- saved lexical memory raises the first-1,000 replay by about 6.5 points;
- no neutral predictions;
- character order is lost; and
- there is no trained weight checkpoint beyond the lexicon.

Decision: **keep as the canonical simple baseline and lexical-memory
component**, not as a competitive NLI model.

### v3

Intent: chain encoding plus basin attraction, collapse, Moksha, clarity
statistics, and a tiny decision head.

Artifact reality:

- static replay is 36.06% and never predicts contradiction;
- the saved lexicon does not change the first-1,000 predictions;
- `peak_clarity.pkl` survives and is loaded;
- `decision_head.pkl` stores native prototype/weight statistics, not the
  README-described two-layer MLP; and
- the default classifier does not load that head.

The orphan head records `alpha=1.99975`, `beta=0.52727`, `gamma=0.48545`, and
`delta=1.06158`, plus class prototypes based on approximately 4,100 examples
per class. Peak-clarity statistics contain 3,336 entailment and 3,329
contradiction observations, with mean resonance 0.6114 and 0.5806
respectively.

Decision: **preserve the prototype/basin design and orphan head as historical
mechanisms**. There is no evidence here that they improve NLI.

### v4

Intent: an eight-layer “planet” that discovers laws from geometry without
manual tuning.

Artifact reality:

- default classifier accuracy is 33.85%, almost all neutral;
- the saved decision tree is an ordinary supervised tree trained from features
  logged beside the true labels;
- `rule_discovery.py` fits and scores on the same 13,988 rows, producing the
  saved **48.37% resubstitution accuracy**;
- on the separate named `features_test.csv` of 100 balanced-ish rows, the saved
  tree gives **46.0%**, versus a 35% majority baseline;
- the default v4 classifier does not load the tree and instead uses hand-coded
  rules described as geometry-discovered;
- the guide's 85.23% is example output, not an artifact; and
- its numerical report is stale: it reports a 7,900-word/322,398-byte brain
  while the actual v4 state has 5,324 words/216,594 bytes, and its cluster
  counts disagree with the surviving cluster files.

The surviving cluster summary records 684 cold, 465 far, and 8,839 city
examples, total 9,988. Only the cold and far cluster files survive; the city
file is missing. The numerical report instead records 591/554/8,843, so it
cannot be treated as a coherent snapshot of the current artifact directory.

Decision: **keep the layered representation and the 46% tiny rule-tree
diagnostic**. Retire the no-supervision, 85.23%, and law-discovery readings.

fractures, semantic warp, and geometry-first training.

Artifact reality:

- default static replay is 33.97%, almost all contradiction;
- debug mode returns the supplied gold label and gives exactly 100%;

- normal-force pattern means overlap heavily across classes; and
- proposed divergence calibration uses class-labeled means and is a supervised

Reusable component: `semantic_warp.py` implements a dynamic-time-warping-like

presence does not establish new physics.

Decision: **preserve source and pattern history; retain semantic warp as a
candidate engineering component; retire debug/self-label scores as NLI

## Fracture and negation claim

Two different mechanisms share the fracture name:

1. `fracture_detector.py` explicitly removes a hard-coded list of negation
   tokens to construct a “ghost” sentence.
2. `fracture_dynamics.py` finds the largest aligned cosine mismatch above a
   threshold.

The first can demonstrate a negation perturbation because negation is supplied
by hand. The second does not distinguish negation from ordinary lexical
difference.

Fresh diagnostic on the first 1,000 valid SNLI test examples:

- 866/1,000, or **86.6%**, were marked fractured;
- only 15 hypotheses contained an explicit token from the diagnostic negation
  list;
- all 15 were fractured, but so were 851 examples without explicit negation;
- 281 of 866 fractured examples were contradictions; and
- `P(contradiction | fracture) = 32.45%`, essentially the 32.9%
  contradiction base rate.

Decision: **retire fracture-as-negation detection**. Preserve maximum alignment
mismatch as a generic diagnostic feature only after calibrating it against
ordinary lexical and syntactic controls.

## Test-suite integrity

Raw pytest collection fails because the archived package expects an
`experiments` namespace that the flattened location does not provide.
A temporary read-only namespace shim exposed the current source for inspection.

With that import issue isolated:

- v8 still fails collection with its real indentation error;
- v5 `test_fracture_dynamics.py` calls the constructor with obsolete
  `relief_threshold`, while source expects `fracture_threshold`;
- excluding those blockers, pytest reports six passes, but five functions
  return booleans instead of asserting, so pytest warns and ignores the result;
- the remaining apparent pass exits early because its SNLI path contains an
  extra `nli/` segment and does not reach its assertion; and
- nine functions in `test_all_laws.py` are collected as tests with nonexistent
  fixtures, producing errors, while the tenth returns a diagnostic dictionary.

The suite therefore contains **no trustworthy green assertion set** for the
physics/law claims. Direct smoke scripts can print success even when their
boolean result is false.

Decision: treat all “tests passed” wording in this archive as unverified until
the tests are rewritten with assertions, correct paths, explicit fixtures, and
failure exit codes.

## Ideas retained

1. **Lexical supervision can help a weak geometric baseline.** The simple saved
   polarity memory is the only state with a measurable current effect.
2. **Sequence alignment is separable from physics language.** Semantic warp is
   dynamic time warping over cosine costs and can be tested honestly as such.
3. **A layered state trace can aid diagnosis.** v4/v5 expose intermediate
   attraction, collapse, opposition, and decision states even though the
   resulting classifier is weak.
4. **Learned state must enter the inference path.** Orphan heads, unloaded
   brains, instance-local updates, and unsaved shared state cannot support a
   result.
5. **Targets define evidence.** Predicting injected gold labels, artificial
   forces, training rows, or self-generated geometry labels is not held-out
   SNLI.
6. **Negative results are design memory.** The archive documents class collapse,
   lexical collisions, uncontrolled hashing, overactive fracture detection, and
   test functions that cannot fail.

## Preservation and continuation decision

- Preserve one canonical account of all eight generations and their artifact
  hashes.
- Classify the two additional roots as semantic mirrors, not replications.
- Keep `nli_simple` as the historical baseline and lexical-memory reference.
- Preserve v3 prototypes, v4 layer traces/rule artifacts, v5 semantic warp and
  pattern history, and v6's opposition-axis experiment.
- Keep v7/v8 as failed-continuation evidence; do not silently repair them and
  then attribute a new result to the historical versions.
- Do not promote any NLI-ALL generation over the valid learned SNLI checkpoints
  already recorded elsewhere in this memory.
- Do not repeat a result without pinning `PYTHONHASHSEED` or replacing built-in
  hash with a stable hash.
- If any component is revived, evaluate it against hypothesis-only, lexical,
  linear/MLP, and matched sequence-alignment baselines under a structurally
  label-blind API.
