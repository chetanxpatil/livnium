The conservation law
SW = 9·f  ·  f ∈ {0, 1, 2, 3}  ·  ΣSW = 486 for N = 3

Every cell has an exposure class f — how many faces it shows. Hidden core: 0. Face-center: 1. Edge: 2. Corner: 3. Weight is 9·f, and the total is conserved by every one of the 24 rotations. Not approximately. Exactly.

Try it
# pure Python, no dependencies — this runs, verbatim
from livnium_core import lattice, rotations, base27

field = lattice.sw_field(3)   # 27 cells, ΣSW = 486
for R in rotations.rotation_group():  # all 24 elements…
    assert sum(lattice.rotate_field(field, R).values()) == 486  # …conserve the total

# and the codec never loses a bit
base27.int_to_base27(base27.base27_to_int("z") + base27.base27_to_int("a"))  # → "a0"
