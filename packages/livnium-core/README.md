# livnium-core

The proven, dependency-free mathematics of Livnium: base-27 codec, lattice,
cube rotation group, exposure-class hierarchy, ping/path signatures, and the
layer language. No Torch, no checkpoints, no experimental claims — everything
in here is covered by the tests in `tests/`.

Install:

```bash
pip install -e packages/livnium-core
```

See the repo-root `README.md` and `docs/` for the full picture.
