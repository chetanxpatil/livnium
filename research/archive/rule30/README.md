# research/archive/rule30/ — the Rule-30 prediction investigation

Can the collapse engine predict Rule 30's center column? A self-contained
investigation (moved from the repo root, 2026-07-02).

Read in this order: `honest_rule30_test.py` (the fair test) →
`genuine_prediction_rule30.py` / `light_cone_rule30.py` (what prediction would
even mean) → `collapse_engine_rule30.py`, `funnel_rule30.py`,
`scaffolding_rule30.py`, `extract_formula_rule30.py`, `final_answer_rule30.py`,
`new_scale_rule30.py`, `select_from_flips.py` (the attempts). The two
`Rule30_*.docx` files are the written assessment and the full journey memo.

All scripts are standalone: `python3 research/archive/rule30/<script>.py`.
