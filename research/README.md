# Active research

`research/` is for live questions and probes, not for stable packages or promoted
models. A project moves to `models/` only after it has a checkpoint, evaluation,
and clear run path; superseded work moves to `archive/`.

| grade | component | status |
|---|---|---|
| **A** | `ramsey/` | Exhaustively verified R(4,5) witness work and conserved sum-tree benchmark. |
| **B+** | `chat-brain/` | Active personal char→word→conversation generation ladder. |
| **B** | `exact-gradient/` | Conservative cosine-gradient variant of collapse. |
| **B** | `language-probes/` | Ordered, relational, gravity, and ping representation tests. |
| **B−** | `vision/` | Pixel/image/foveal collapse prototypes with useful negative diagnostics. |
| **C+** | `discrete-chat/` | Discrete-cube generation experiment; mainly a mechanism test. |
| **C** | `qwen-hook/` | One integration probe, not a standalone result. |

Grades reflect reproducibility and evidence. They are allowed to change when a
matched benchmark or stronger checkpoint changes the facts.
